Swiper 配置

目标配置只有四项要求，但第一版回答并未全部满足。下面是两轮提示词、两版代码，以及页面内的实时验证。

  • ① 无缝循环loop 开启后首尾衔接
  • ② 自动翻页3.2 秒一次，手动后不停
  • ③ 圆点可点击点击分页器跳转
  • ④ 初始效果effect 为 cube

第 1 轮 · 需求原样交给 AI

3 处问题

我的提示词

用 Swiper 写一个轮播：要无缝循环、3.2 秒自动翻页并且手动操作后不要停、圆点分页器可以点击、初始效果是 cube。

AI 返回的代码

const mySwiper = new Swiper('#mySwiper', {
  loop: true,
  autoplay: 3200,
  effect: 'cube',
  pagination: { el: '.swiper-pagination' }
});

粘进页面后发现的问题

  • autoplay: 3200 是旧版写法，Swiper 11 不再接受数字，结果完全不自动播放。
  • 没有写 disableOnInteraction: false，默认值会让用户手动滑动后永久停止自动播放。
  • 分页器缺少 clickable: true，圆点只能看不能点。

第 2 轮 · 把每条要求变成可检查的约束

4 项全部满足

我的提示词

请按 Swiper 11 的对象写法重写，并逐条对应我的要求：
1. loop 必须为 true，实现无缝循环；
2. autoplay 必须是对象，delay 为 3200，且必须写 disableOnInteraction: false，保证手动滑动或点箭头后仍然继续自动播放；
3. pagination 必须是对象，包含 el 与 clickable: true；
4. effect 固定为 'cube'。
请只输出一段可直接运行的 new Swiper 配置，并在注释里标明每条需求对应哪一行。

AI 返回的代码（已采用）

const mySwiper = new Swiper('#mySwiper', {
  loop: true,                                          // ① 无缝循环
  effect: 'cube',                                      // ④ 初始效果 cube
  speed: 650,
  autoplay: {
    delay: 3200,                                       // ② 3.2 秒自动翻页
    disableOnInteraction: false                        // ② 手动操作后不停止
  },
  pagination: {
    el: '.swiper-pagination',
    clickable: true                                    // ③ 圆点可点击
  }
});

答辩准备

第一版提示词漏掉了什么？

漏掉了"手动操作后不要停"这条的实现方式。我写了需求，却没有约束 autoplay 必须用对象写法，AI 就按旧版语法返回了数字，这条需求等于没被满足。

第二轮怎么"说清楚"的？

把一句话需求拆成四条可检查的断言，每条都指名具体属性与具体值，并指定 Swiper 版本、要求逐行注释对应关系。约束越具体，AI 越没有自由发挥的空间。

AI 第一次的代码错在哪？

三处：autoplay 用了已废弃的数字写法导致完全不播放；缺少 disableOnInteraction: false 导致手动后停止；pagination 缺 clickable: true 导致圆点不可点。
